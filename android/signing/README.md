# Подпись NOX Android

Здесь лежит только **публичный** отпечаток постоянного сертификата
(`expected-cert-sha256.txt`). Сам ключ и пароли в репозитории не хранятся
никогда: CI получает их из GitHub Secrets

- `NOX_ANDROID_KEYSTORE_BASE64` — файл ключа (PKCS#12) в base64;
- `NOX_ANDROID_KEYSTORE_PASSWORD` — пароль хранилища;
- `NOX_ANDROID_KEY_ALIAS` — имя ключа;
- `NOX_ANDROID_KEY_PASSWORD` — пароль ключа.

Если секретов нет, CI не публикует релиз вовсе — временных ключей больше
нет. Перед публикацией CI сверяет сертификат собранного APK с отпечатком
из этого файла: APK, подписанный чем-то другим, не выйдет.

Отпечаток меняется только вместе с осознанной ротацией ключа
(APK Signature Scheme v3), иначе установленный NOX перестанет принимать
обновления.
