# Снимки экрана NOX 0.4.0

Настоящие снимки отладочной сборки 0.4.0 с эмулятора Android 14 (API 34,
x86_64, 1080×2400, 420 dpi), работавшего без аппаратного ускорения.
Контрольный вид: обои «Лиса NOX», тема «Янтарь», стекло «Авто».

Медиатека на снимках — **демонстрационные данные отладочной сборки**
(`androidTest/DemoLibrarySeed.kt`): короткие ролики и обложки собраны
процедурно, у коллекций подпись «Демонстрационные данные отладочной
сборки». В релизной сборке этих данных нет: новая установка начинается с
пустой медиатеки.

Загрузки и загрузчик сняты на локальном стенде эмулятора (`10.0.2.2:8766`,
HTTP разрешён только отладочной сборке): страница с HTML5-видео в четырёх
качествах и двумя дорожками субтитров, большие файлы с ограниченной
скоростью отдачи. Живой YouTube на этих снимках не участвует.

Каждый файл `nox-0.4-compare-*.png` — макет слева и снимок приложения
справа, приведённые к одной высоте. Отдельно лежат сами снимки
(`nox-0.4-0N-*.png`).

- `01` — главная «Коллекции».
- `02` — загрузчик: найденное видео, четыре качества с размерами (узнаны
  заголовками ответа), выбранные субтитры «Русский».
- `03` — очередь: две активные загрузки, пауза, завершённые.
- `04` — плеер: сериал «Клинки рассвета», 2 сезон, 6 серия; ряд серий
  сезона, «Только звук», таймер сна.
- `05` — настройки.

`nox-0.4-recording.mp4` — короткая запись экрана того же эмулятора
(`adb shell screenrecord`). Эмулятор без ускорения рисует несколько кадров в
секунду, поэтому анимации на записи рывками; на телефоне они плавные.

Снимки прошлых версий — в `archive-0.3/`.
