# Снимки экрана NOX 0.2.0

Настоящие снимки с эмулятора Android 14 (API 34, x86_64, 1080×2400,
уменьшены до 720×1600). Эмулятор работал без аппаратного ускорения.

- Приложение — отладочная сборка того же кода, что и релиз 0.2.0.
- Данные тестовые. Видео сгенерированы заранее, база 0.1.0 заполнена
  вручную, затем 0.1.0 обновлена до 0.2.0 без удаления данных. Поэтому
  на снимках видны перенесённые позиции просмотра и загрузка на паузе.
- Режим стекла на большинстве снимков — «Экономичный». Программный
  рендерер эмулятора падал при «живом» размытии (RenderEffect). Снимок
  `nox-04-video-menu-live-glass.png` сделан в режиме «Авто» с живым
  размытием, до того как эмулятор упал.
- `nox-08-picture-in-picture.png` — плеер в окне «картинка в картинке»
  на рабочем столе Android.
