# Снимки экрана NOX

Настоящие снимки с эмулятора Android 14 (API 34, x86_64, 1080×2400,
уменьшены до ширины 720). Эмулятор работал без аппаратного ускорения и
без доступа в интернет.

## 0.3.0

- `nox-02-downloads.png` — экран загрузок 0.3.0 после обновления поверх
  настоящей 0.2.1 с данными: поле ссылки, «Найти видео» вместо кнопок
  360/480/720/MAX, в очереди — задание 0.2.1 на паузе с сохранённой частью,
  тема «Янтарь» и свой фон перенесены.
- `nox-05-batch-links.png` — «Несколько ссылок»: у каждой ссылки будет свой
  разбор и свой выбор качества.
- `nox-10-download-settings.png` — «Качество по умолчанию» (только
  предварительный выбор) вместо фиксированной кнопки.
- `nox-11-quality-variants.png` — список вариантов качества. Это
  компоненты приложения, отрисованные инструментальным тестом
  `VariantListUiTest` на **записанном** ответе YouTube (yt-dlp 2026.08.19,
  ролик Big Buck Bunny 60fps с 1440p и 2160p). Живой запрос к YouTube с
  эмулятора сделать было нельзя: у эмулятора не было сети, а сеть CI YouTube
  отклонил проверкой «не бот». Цвета — палитра по умолчанию, вне темы.
- `nox-06-appearance.png` — «Оформление»: в предпросмотре вместо кнопок
  качества показана строка варианта.

## 0.2.0 (не менялись)
