# Дизайн NOX 0.4.0

`references/01…05` — пять утверждённых макетов (главная с коллекциями, загрузчик,
очередь загрузок, плеер, настройки). Интерфейс собран из настоящих Compose-компонентов
по их мерам (853 px макета ≈ 411 dp); картинки макетов в приложение не попадают.

## Откуда графика

- `app/src/main/res/drawable-nodpi/wallpaper_fox.jpg` — обои «Лиса NOX». Отдельного
  чистого исходника янтарной лисы в материалах проекта нет, поэтому верхняя часть
  (лиса) собрана из самих макетов 01–03: совмещены три кадра, текст и элементы
  интерфейса убраны масками и восстановлением фона, левый верхний угол (где на
  макетах логотип) размыт. Нижняя часть — процедурный тёмный фон с янтарными
  волокнами по краям, продолжающий настроение макетов; граница с верхней частью
  растушёвана. Ограничения: разрешение исходника — 853 px по ширине макета, поэтому
  на больших экранах лиса мягче, чем на макете; нижняя часть — приближение, а не
  копия исходной картины.
- `app/src/main/res/drawable-nodpi/nox_logo_amber.png` — буквы NOX, вырезаны из
  макета 03 с восстановлением прозрачности. Подписи под логотипом («офлайн-медиатека»,
  «Твои видео. Всегда с тобой.») — настоящий текст, а не часть картинки.

## Отличия от макетов (сознательные)

- «JAM» на макете плеера — не кодек; в NOX на этом месте настоящие кодеки файла.
- «2108» на макете настроек — не номер сборки; показывается настоящий versionCode.
- «Одновременных загрузок 1 / 3 / 5» → в NOX **1 / 2 / 3**: больше трёх одновременных
  передач NOX не делает.
- «Поддерживаются: YouTube, VK, Rutube и др.» → «YouTube, VK и др.»: потоковые HLS/DASH
  (так отдаёт видео Rutube) NOX пока не скачивает, обещать их нельзя.
- «Экспорт настроек — сохранить в файл» → «в папку»: копия NOX — папка с файлами.
- На макете очереди нет общих действий; в NOX над списком — строка «Добавить видео /
  Пауза для всех / Продолжить все / Повторить ошибки», без неё массовые действия
  были бы недоступны.
- Шрифт — системный Roboto (на макетах — SF Pro), поэтому ширина строк чуть отличается.
