# Обновление 0.3.0 → 0.4.0 → 0.4.1 с данными

Эмулятор Android 14 (без ускорения). Стояла официальная `NOX-Android-v0.3.0.apk`
(`com.nox.offline`, versionCode 4) с медиатекой из 4 видео, позициями
просмотра и незавершённой загрузкой в очереди.

Поверх неё поставлены **опубликованные** файлы выпусков
`NOX-Android-v0.4.0.apk` и затем `NOX-Android-v0.4.1.apk` (SHA-256 совпадает
с `nox-update.json`; подпись — тот же постоянный сертификат, что у 0.3.0).
Установка — `adb install -r`, то есть обновление поверх, без удаления данных;
`firstInstallTime` остался прежним.

Кнопка «Проверить обновления» в 0.3.0 на этом эмуляторе ответила «Нет
соединения с GitHub»: в среде сборки весь TLS к github.com переподписывается
шлюзом песочницы, и приложение правильно не доверяет такому сертификату.
Путь «кнопка → скачивание с GitHub» здесь не проверен.

- `01` — 0.3.0 до обновления.
- `02` — 0.4.0: те же 4 видео и позиции («Байкал зимой» — 0:16, «Ночной город» — 0:12), ничего не играет само.
- `03` — 0.4.0: незавершённая загрузка «Лекция о звёздах» сохранена (55%).
- `04` — 0.4.0: тема «Янтарь» и стекло «Экономичный» из 0.3.0 сохранены, обои не заменены.
- `05` — 0.4.1: ряд «Все видео» на главной у человека без коллекций.
